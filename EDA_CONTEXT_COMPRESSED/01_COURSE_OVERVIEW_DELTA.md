# 课程安排压缩：工程流程与验收上下文

> 来源：`集成电路EDA实验课_课程安排.pdf`。这是课程概览材料，**不是最终项目规范**；与 V1.7 指导书冲突时以后者为准。

## 1. 整体工程链路

课程要求完成一个北斗 B1I 数字基带：

```text
离线 2-bit 实中频
    ↓
输入/公共时基
    ↓
捕获 → 12 路跟踪 → NH/位同步 → 帧同步/D1 解调
    ↓                         ↓
测量记录                  导航参数
    └────────→ 输出汇聚/适配 → RINEX OBS + NAV → 定位软件

同一份 RTL：功能仿真 → DC 综合 → ICC 布局布线 → STA → DRC/LVS
```

课程概览给出的参考架构就是“并行捕获 + 12 路跟踪 + 输出单元 + 配套 RINEX/导航软件”。流程控制器与卫星管理分开，通道状态需要能表达锁定、同步和失锁。（PDF p.4）

## 2. 必做功能

- 捕获：搜索指定 PRN、码相位和载波频偏，做检测判决；结果必须带参考时标。
- 码/载波跟踪：PRN、NCO、混频、E/P/L 积分、DLL/PLL（课程材料也提到 FLL 辅助）。
- 同步与解调：NH 同步/去除、位同步、帧同步、极性、去交织、BCH，恢复 D1 数据。
- 测量：组合整数码周期、分数码相位和导航时间，形成共同接收历元下的有效观测。
- 多通道：12 个逻辑通道共享同一输入样本流和公共时基。
- 边界/异常：复位、输入停顿、积分边界、失锁、重捕获、计数回绕，不能产生“伪有效”结果。（PDF p.9）

## 3. 输出责任边界

RTL 应输出结构化记录，而不是自己拼 RINEX 文本：

- 测量记录：PRN、公共接收样本号、整数码周期、分数码相位、导航时间关联、有效状态；
- 导航记录：D1 解码数据、PRN、有效位数、接收时标、同步/译码状态；
- 软件侧适配：RINEX 3.05 OBS/NAV；B1I 伪距 `C2I` 是基础观测类型。（PDF p.8）

原则：只输出真正从接收链恢复的数据；缺测留无效，不能用模拟器真值补齐。

## 4. 评价证据

课程不是“波形能跑就算完”。需要同时留下三类证据：

1. **功能**：码序列、积分边界、捕获/锁定/失锁、D1 比特/译码、观测时标；
2. **应用/性能**：捕获率、虚警率、捕获耗时、跟踪/解调门槛、动态压力、伪距/定位误差；
3. **ASIC 实现**：setup/hold、实际吞吐、面积/功耗条件、DRC/LVS、最终版本一致性。（PDF pp.10–11,16）

最终还要求 RTL、约束、网表、版图和验证报告使用同一版本标识。

## 5. 课时只是进度参考

72 学时的大致分配：原理/分解 4h，架构/定点 8h，捕获/跟踪 16h，电文/测量 12h，多通道/定位 4h，综合/约束 6h，布局布线/时序 12h，物理验证 6h，展示答辩 4h。（PDF p.12）

这说明前端基带与后端 ASIC 流程都属于正式交付，不宜把综合/布局布线当成最后临时补做。

## 6. 已知版本冲突：不要固化旧数值

课程安排 PDF p.7 写：

```text
IF = 4.096 MHz
Fs = 16.384 MSps
1 ms = 16384 samples
```

后发布的《EDA 实验指导书 V1.7》给出的项目要求是：

```text
IF = 4.092 MHz
Fs = 16.368 MHz
```

因此本文件只保留旧课件作为“版本历史”。RTL/测试向量/计数常量必须从 V1.7 和实际配套配置取得，禁止因为这份旧课件写死 16384。
