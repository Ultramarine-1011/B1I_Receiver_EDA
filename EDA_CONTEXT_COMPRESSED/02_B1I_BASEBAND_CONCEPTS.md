# 北斗 B1I 基带概念压缩

> 来源：`北斗B1I基带与位置解算基础.pdf`。用途是建立模块间直觉；精确码表、电文字段以 B1I ICD 为准。

## 1. 整条链路到底在恢复什么

输入是一条所有卫星叠加后的 2-bit 实中频样本流。基带逐层恢复：

```text
x[n], sample_count
  ↓
捕获：PRN + 粗码相位 + 粗多普勒 + 参考时标
  ↓
跟踪：连续码相位/码周期 + 连续多普勒/载波状态 + Prompt I/Q
  ↓
NH/位同步：50 bit/s 数据位 + 位边界
  ↓
帧同步/D1 解码：卫星时间 + 星历/钟差等导航参数
  ↓
测量：公共接收历元下的伪距/多普勒等
  ↓
配套软件：RINEX → 位置与接收机钟差
```

这条链路最重要的共同变量是**时间**：每个中间结果都必须能追溯到它对应的输入样本位置，而不是只记录“计算完成的 clk 周期”。（PDF pp.9–18）

## 2. B1I 的三个时间尺度

课程概念材料给出的 B1I D1 关系：

- 主码：2.046 Mcps，2046 chip，周期 1 ms；
- NH20：1 kchip/s，1 个 NH chip = 1 ms = 1 个完整主码周期；
- D1：50 bit/s，1 bit = 20 ms = 20 个 NH chip = 20 个主码周期。（PDF pp.4–5）

因此实现中至少要把以下状态分开：

```text
逐样本 NCO/相关
1 ms 相关积分/主码周期
20 ms NH/数据位
子帧/电文时间
1 s（或配置值）公共观测历元
```

不要试图用一个“总状态机”直接跨越这些时间尺度。

## 3. 输入语义

概念材料的最终输入页给出：2 bit 实 IF，编码 `00→-3, 01→-1, 10→+1, 11→+3`；有效样本必须有连续编号，后续所有时间关系基于该编号。（PDF p.10）

注意：概念材料 PDF p.6 为画图方便使用过 4.096 MHz 中频，p.10 则写 4.092 MHz / 16.368 MSps；这正说明概念课件不能作为参数规范。工程参数以 V1.7/配套配置为准。

## 4. 捕获

捕获回答三个问题：

```text
哪颗星？     PRN
码在哪里？   code phase
频率差多少？ Doppler/frequency offset
```

搜索空间是“码相位 × 频偏”。每个格点代表一组本地 PRN 延迟和本地载波频率假设，相关峰超过门限才判定存在。（PDF pp.8,11）

工程输出不要只给 `(code_phase, doppler)`，还必须给 `reference_sample/time`，否则跟踪初始化时不知道这些估计对应输入流的哪个位置。

## 5. 码跟踪 DLL

相关器生成 Early / Prompt / Late。DLL 根据 Early 与 Late 的不平衡估计码偏差，经滤波得到码速/码相位修正，反馈到 Code NCO；当 E/L 趋于对称时，本地码接近正确对齐。（PDF p.12）

工程上应保留：

```text
I_E,Q_E,I_P,Q_P,I_L,Q_L
integration/window reference
code_error / code_ctrl
code_phase / code_period_count
code_lock / quality
```

## 6. 载波跟踪 FLL/PLL

Prompt I/Q 构成复相关值。FLL 用于频率拉入，PLL 用于精细相位跟踪；捕获给出的主要是频率初值，不等于已经知道绝对载波相位。（PDF p.13）

Prompt 不能只在载波环内部消费后丢掉，因为同步/电文链还需要它的软信息。

## 7. NH、位同步与 D1

每 1 ms 有一个 Prompt 相关结果。先找到 NH20 起点并消除 NH 符号翻转，再把 20 个 1-ms 块组合成一个 50 bit/s 数据位。（PDF p.14）

之后寻找子帧边界并完成字处理、去交织/纠错，再提取时间、轨道、钟差、健康状态等参数。概念材料指出 D1 一帧含 5 个子帧、总时长 30 s，基础星历主要在子帧 1–3；具体字段必须回查 ICD。（PDF p.15）

## 8. 伪距不是“相关峰位置”

形成伪距至少需要：

```text
分数码相位
+ 整数码周期计数
+ 从电文恢复的卫星时间锚点
+ 公共接收历元
```

物理关系是传播时间乘光速；由于接收机时钟与系统时不同步，结果称为伪距并包含接收机钟差。（PDF p.16）

因此：捕获码相位只是初值，单个 1-ms 周期内的码相位也不足以直接得到完整伪距。
