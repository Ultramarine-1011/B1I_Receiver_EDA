# EDA 工程压缩参考资料包

用途：给 Codex / Cursor 提供**小而明确**的工程背景，避免每个会话反复读取大段 PDF。

## 使用原则

工程根目录仍建议保留：

- `plan.md`：当前架构合同与阶段计划。
- `EDA_ENV_STATUS.md`：实验机、虚拟机、EDA 工具环境事实。

规范原文仍建议完整保留，不用本压缩包替代：

- `集成电路EDA实验指导书_V1.7(1).pdf`
- `北斗_B1I_B2I_ICD_2.1版_中文版.pdf`

本目录中的 Markdown 都属于**参考摘要**。出现冲突时，优先级建议为：

1. 《集成电路 EDA 实验指导书 V1.7》中的项目/接口/验收要求；
2. 北斗 B1I/B2I ICD 2.1 中的信号与电文规范；
3. `plan.md` 中已经冻结的工程架构决策；
4. 本压缩包中的课程材料和专题文献摘要。

## 默认上下文

新 Codex/Cursor 会话不必读完全部摘要。建议默认只读：

```text
AGENTS.md
plan.md
EDA_ENV_STATUS.md
docs/context/00_CONTEXT_INDEX.md
```

做到具体阶段时，再加载对应摘要；若遇到精确码表、电文字段、验收条款，再回到原始 ICD / 指导书核对。
