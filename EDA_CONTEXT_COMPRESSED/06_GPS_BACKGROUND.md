# GPS 教材试读：仅保留可迁移的导航背景

> 来源：`GPS卫星导航定位技术与方法_出版社试读.pdf`（试读仅覆盖全书前部）。这份材料用于理解通用 GNSS 原理，**不能作为北斗 B1I 码/电文规范**。

## 1. 三种无线电定位直觉

试读第 1 章先介绍：

- TOA/测边交会：传播时间 × 光速得到距离，多条距离约束确定位置；
- TDOA/双曲线：利用到不同基站的时间差；
- Doppler：利用频移得到视向速度/距离变化。（PDF pp.9–11）

本课程直接相关的是 TOA/伪距定位和 Doppler 跟踪：基带一方面恢复码传播时间信息，另一方面持续估计载波频偏。

## 2. PRN 为什么适合测距

教材强调伪随机码具备可重复生成、周期性和接近随机序列的相关性质；正确对齐时自相关强，错误位移时相关弱，因此接收机可以用本地复制码做相关搜索和跟踪。（PDF pp.17–19）

这解释了整个基带结构为什么围绕“本地 PRN + 相关器”展开。

## 3. GPS C/A 例子只用于类比

试读介绍 GPS C/A：Gold-code 风格的移位寄存器生成、1.023 Mcps、1023 chip、1 ms 周期，并通过相关完成捕获与跟踪。（PDF pp.19–21）

与本项目 B1I 的相似点：

```text
都使用 PRN/CDMA 思路
都有 1 ms 主码周期
都依赖相关做捕获/跟踪
```

但参数不同。B1I 是 2.046 Mcps、2046 chip，并有自己的 G1/G2 多项式、抽头/相位分配、NH20 和 D1 格式。实现时必须查北斗 ICD。

## 4. 信号链的通用分层

教材把卫星信号理解为“载波 + 测距码 + 导航数据”。对数字基带而言，这自然对应：

```text
载波层 → mixer / carrier NCO / FLL-PLL
测距码层 → PRN / code NCO / correlator / DLL
数据层 → secondary-code/bit/frame sync / decode
```

这是一种很好的模块划分直觉，但所有 B1I 数字细节仍以 ICD 为准。（PDF pp.21–22）

## 5. 对本工程的用途到此为止

这份 30 页试读包含大量 GPS 历史、星座和 GPS 专用 C/A/P 码细节，对当前 B1I ASIC 实现价值有限。Codex/Cursor 默认不需要加载原 PDF；只有在需要通用定位直觉时读本摘要即可。
