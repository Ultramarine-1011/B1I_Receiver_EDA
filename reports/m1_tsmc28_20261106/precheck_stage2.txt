PAD / I/O libraries for the TSMC28 teaching installation
I/O: TPHN28HPCPGV18 170A, 0.9V core / 1.8V I/O, physical views 110A mt_2/9lm.
Bond pads: TPBN28V CUP 9M_4X2Y2R APF 140B / APT and GDS 140A.
Optional alternatives: TPBN28V MTRDL 9M_R and APRDL flip-chip views.
Install root: /home/share/libs/tsmc28/pad
Do not combine alternative bond-pad libraries with duplicate cell names in one reference list.
The 14 I/O kits match the TPHN28HPCPGV18 170A release-note dependency table.
All 21 selected archives were checked member-by-member against the extracted files.
Celtic ctc is a crosstalk/noise database, not a clock-analysis library.
File integrity verification is not an ICC integration or DRC/LVS signoff result.
The supplied source tree has no separate TPBN28V release-note, databook, LEF or SPICE kit.
Consult the included I/O release note and General I/O application note; do not assume missing
Bond Pad documentation or project-specific requirements have been satisfied.
The optional MTRDL source archives contain several metal stacks despite their filename;
all vendor members are preserved. For the 9M_R option choose the actual 9m/9M_R subdirectory.
I/O SPICE and Verilog contain 109 cells; 14 physical-only corner/filler cells have no such models
in the original vendor kits. NLDM/LEF/ICC FRAM cover all 123 I/O cells.
