## 目标

完成并验证单通道北斗 B1I 跟踪链：从数字中频样本到稳定的码/载波跟踪输出，包含 Code NCO、E/P/L、Carrier NCO/Mixer、DLL、FLL/PLL，具备 Python reference/golden models、SystemVerilog RTL 和自检 VCS 回归。

这是单通道算法与功能 RTL milestone。现有系统架构仍以 `plan.md` 为基线，已有参数和时间语义见 `docs/ARCHITECTURE.md`、`docs/PRN_GENERATOR.md` 与 `docs/CODE_NCO_EPL.md`。

## Scope

复用现有 `b1i_prn_gen`、`code_nco`、`epl_correlator`，自主拆分、排序和迭代以下工作：

- Carrier NCO 和 digital carrier mixer。
- E/P/L 及 Prompt I/Q integration；复用已有 Prompt 累加路径，保留未硬判决软信息。
- DLL discriminator、loop filter 和 Code NCO feedback。
- FLL/PLL discriminator、loop filter、模式切换及 Carrier NCO feedback。
- 基础 `code_lock`、`carrier_lock`、`tracking_valid`、质量与失锁状态。
- 单通道内部必要的初始化、反馈生效和时序连接。
- 独立全精度模型、位精确 golden model、可重复的信号激励和评分。
- SystemVerilog RTL、自检 VCS 模块回归与单通道闭环回归。
- 数学、定点、接口、测试条件和误差/收敛结果文档。

范围外：acquisition、`global_ctrl`、`sat_manager`、12 通道集成、完整 SRAM 输入系统、NH/位/帧同步及 D1 解码、测量/OBS/NAV 输出、正式综合/PPA 和 ICC/PT 后端流程。可在测试激励中模拟相关信号影响，但不因此实现范围外模块。

## Design method

1. 先核查现有模型、RTL、接口和历史证据，识别本 milestone 的依赖。
2. 对未冻结的算法/定点参数，先建全精度模型、扫描合理候选、记录误差与资源依据，再冻结第一版实现；普通可逆设计选择自主完成。
3. 明确载波频率/相位及 I/Q 符号、码相位、控制字单位、积分/环路更新周期、流水延迟、反馈生效样本和初始化参考位置。
4. 维持当前样本使用当前状态、完成相关后推进 NCO 的时间语义；有效样本空拍保持、窗口首末边界及 reset/init 优先级均须验证。
5. 课程未发布的配置继续参数化。系统 `clk` 与 SRAM 配置缺失不阻塞逐 `sample_valid` 模型和功能 RTL；课程实际数据验收与可重复合成信号验证应分开记录。
6. 全精度、位精确和 RTL 的验证分别保留证据，不能用同一实现的自我比较替代独立参考。闭环真值仅供评分使用。
7. 每项参数写明来源：课程要求、ICD、推导，或自主扫描后选定的工程 baseline；修改已有 baseline 时说明影响并重跑相关回归。
