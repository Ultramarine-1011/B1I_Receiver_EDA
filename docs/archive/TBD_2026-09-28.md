## 已解决的输入信号与首批跟踪参数

以下输入物理参数来自《集成电路 EDA 实验指导书 V1.7》第 1.2、1.4、2.3 节，不再作为 TBD：

- 输入采样率 `Fs = 16.368 MHz`。
- 实中频 `IF = 4.092 MHz`。
- 每个样本 2 bit，映射为 `00 → -3`、`01 → -1`、`10 → +1`、`11 → +3`；内部重构至少为 signed 3 bit。
- B1I 主码速率为 2.046 Mcps，标称关系为每 chip 8 个样本、每 1 ms 主码周期 16368 个样本。该整数关系不替代 Code NCO 的分数相位处理。
- 若配套 SRAM **按字节组织**，V1.7 给出的排列是最早样本位于 `[7:6]`，随后为 `[5:4]`、`[3:2]`、`[1:0]`；但实际 SRAM 字宽尚未找到，因此这条仍是条件规则，不能据此认定实际接口为 8 bit。

以下是后续经过模型扫描和 VCS 验证的第一版工程 baseline，依据见 [CODE_NCO_EPL.md](CODE_NCO_EPL.md)，不表示指导书指定了这些具体位宽：

- Code NCO 第一版采用 unsigned Q11.32 相位和 unsigned Q1.32 步长，单位分别为 chip 和 chip/accepted-sample；标称步长为 0.125 chip/sample。相位按 2046 chip 回绕。
- E/P/L 的 `delta` 定义为相对 Prompt 的单边偏移；第一版 `delta=0.25 chip`，E-L 总间隔为 0.5 chip，保持参数化。
- 第一版相关窗口为固定 16368 个 accepted samples；末样本计入当前窗口，下一有效样本开启下一窗口，`window_ref` 是窗口首个有效样本的参考位置。
- 对 signed `IQ_WIDTH=W` 的 mixer 输出，第一版最小相关累加器位宽为 `W + ceil(log2(16368+1)) = W+14`，完整和不需要 guard bit、不在相关器内舍入或饱和。

2026-09-28 新 resolved baseline：Carrier 相位/总频率控制字 32 bit，正弦地址 10 bit、对称幅值 12 bit（±2047），3 bit 输入保留 14 bit I/Q 完整乘积；对应 E/P/L 应配置 28 bit 和。I/Q/valid/ref 注册一拍，码值需对应延迟。参数扫描与 VCS 依据见 [CARRIER_NCO_MIXER.md](CARRIER_NCO_MIXER.md)；通道连接尚未完成，不能当作整链验证结论。

旧课程材料摘要 `EDA_CONTEXT_COMPRESSED/00_CONTEXT_INDEX.md` 记录过 `Fs=16.384 MSps、IF=4.096 MHz`。该数值与当前 V1.7 冲突，工程以 V1.7 的 `16.368/4.092` 为准，旧值不得进入 RTL 或验证配置。
