# 2026-11-02 六通道核心

本轮依据 `261102/北斗基带信号处理器六通道逻辑综合实验要求.pdf` 第2节和第6节的功能要求。另已读取 VCD 功耗评估说明和 `tsmc28_学生使用说明.docx`。本轮实现核心及功能仿真；PAD、综合优化、SDF 后仿和功耗是后续工作。

## 复用与结构

E/F/G 已有参数化1/2/4/12通道、共享 PCPS/精搜、独立跟踪/NH/D1、失锁与代次控制。旧整机的真实 IF 证据主要是四星，12 路导航测试是 Prompt 层测试，均不能直接充作六星实收证据。

`bds_bb_6ch_core` 复用六个 `receiver_channel` 和原 PCPS/精搜算法。各槽固定配置 PRN，各自保存码/载波 NCO、DLL/FLL/PLL、锁定、NH、帧、导航时间、代次和记录状态。公共捕获运算按槽轮询；已捕获通道持续并行跟踪，公共捕获引擎对空闲槽抓取新4ms窗并运算。计算器共享，通道配置与处理状态独立；没有复制六套 FFT 存储或重写算法。

旧 `receiver_multichannel`/`student_receiver_core` 也允许 `CHANNELS=6`，保留原16样本与256位记录接口。新核心另设少量控制逻辑，是因为旧控制器在冷捕获计算时停止接收输入、按检测顺序动态分配槽；新规范需要固定槽配置和持续公共样本时间。两条入口共用通道和捕获算法，无真值初相或频偏注入接口。

## 核心端口契约

| 端口 | 方向/位宽 | 采样或生效规则 |
|---|---|---|
| clk / rst_n | 输入，各1 | 上升沿处理；低有效异步复位。实际电路须满足复位释放的恢复/移除预算；本轮 TB 在时钟低沿释放 |
| IF | 输入，2 | 公共实中频；00/01/10/11分别为−3/−1/+1/+3，内部重构为signed 3位 |
| if_valid / if_ready | 输入/输出，各1 | 上升沿两者为1时接受一个新样本。无握手时公共样本编号、运行中NCO及相关积分不前进；发送方在反压期间保留待发送样本 |
| cfg_valid | 输入，1 | 每个高电平时钟沿提交一次配置事务，正常使用单拍脉冲 |
| cfg_channel | 输入，3 | 槽0～5；独立于PRN编号 |
| cfg_prn | 输入，6 | 有效PRN6～37；启用时须合法 |
| cfg_enable | 输入，1 | 1启用，0停用；与cfg_valid同沿生效 |
| capture_ok | 输出，6 | 第i位代表槽i已接纳RTL捕获结果；跟踪拉入阶段也可为1。该槽失锁、拉入超时、重配置或全局复位时清零 |
| bit_sync_ok | 输出，6 | 第i槽已锁定、NH对齐并经合法D1首字确认位极性；失效时撤销 |
| nav_data / nav_valid | 输出，各6 | 第i位对应槽i。nav_valid是一个clk脉冲，接收方在上升沿采样对应nav_data；其余时间数据保持到下个新位或状态清除 |

复位默认六槽启用、PRN依次6～11。外部可在开始送样前逐槽改配，也可运行中改配。重配置只释放对应槽，清除该槽捕获/同步/导航状态并增加下一次分配的代次；其他槽继续处理同一流。若改配槽恰为当前捕获目标，两个搜索引擎一起取消该任务，不接纳旧配置的迟到结果。

样本编号从0开始，只由`if_valid && if_ready`增加。它代表信号时间，逻辑时钟与仿真墙钟分别统计。信号缺失测试保持样本时间连续，只从混合波形中去掉一颗卫星；不能用暂停if_valid模拟RF信号中断。

`PULLIN_SAMPLES=32736000`沿用本工程2秒拉入预算，不是新教师性能门限。曾锁定后锁定撤销立即释放；此前尚未锁定的通道按样本差超时。未捕获槽在公共流经过时不产生伪跟踪数据。

短期重捕保留该槽最后锁定时由接收机自身产生的码NCO相位、步长及样本号。新候选传播到同一预约样本后，与该预测相位比较循环距离；最近2秒内默认限制为16样本（2chip），由`REACQUIRE_RADIUS_SAMPLES`参数给出。这一工程基线沿用精搜16样本的相位尺度；原捕获检测和跟踪锁定门限未调整。状态过旧则恢复无相位限制的全搜索，重新配置则清除旧预测。它拒绝短时RF缺失期间远离既有轨迹的互相关假峰，既不从发送源取得真值，也不永久依赖旧状态。

## 单样本与旧16样本接口

新核心不先打包16个样本再拆包。公共样本直接广播给六槽和捕获窗；捕获计算期间继续接受样本，未分配槽无需保存这些历史样本。只有运行通道本身的短暂处理等待会反压公共输入。

复用教师播放器时，使用原 `stream_unpacker`：`stream_data[1:0]`最早，依次至`[31:30]`；`sample_bits`连到核心IF、`sample_valid`连if_valid、核心if_ready连sample_ready。stream侧沿用原ready/valid和每字+16的sample_index。文件字节`[7:6]`最早，与总线低位最早之间的重排仅由教师播放器完成，不能再次翻转。

旧记录入口 `student_receiver_core #(.CHANNELS(6))` 已通过真实公开输入与输入停顿/输出反压回归；其冷捕获暂停契约保持原样。它用于保留旧测试与记录，不是新标量核心的输入缓存。

Fs=16.368MHz、IF=4.092MHz、Rc=2.046Mcps；每chip8样本，每主码周期16368样本。新核心需要必要采样握手，不能把每clk一新样本且禁止反压当作已满足的接口条件。仿真最密集送样的实测周期/样本和最长反压见[本轮报告](../reports/six_channel_20261102/FINAL_REPORT.md)。另用假定100MHz逻辑时钟、精确16.368MHz相位累加节拍测试持续输入；此处100MHz是功能吞吐测试预算，不是教师给定频率或TSMC28时序结果。

## 捕获到跟踪的时间关系

PCPS抓取4个完整主码周期，保存窗口首样本`coarse_ref`；精搜只读该独占窗口，不被后台新数据覆盖。每次只搜索当前槽PRN，频率搜索网格仍为参数，默认−10kHz至+10kHz、500Hz粗网格，精搜沿用±16sample和±250Hz/50Hz格点。

接纳结果时预约`effective_ref = sample_count + 4096`，按原F设计将捕获参考处码/载波推进到预约样本：码相位为`((16368−lag)%16368)*2^29 + ΔN*code_step`对`2046*2^32`取模，整周期另存；载波相位为`ΔN*(0x40000000+doppler_word)`取低32位。码步长沿用`0x20000000 + doppler_word/763`的载波辅助基线。

PRN最长2046逻辑拍预置；预约之前该槽不接样，不拖停健康槽。因为每个逻辑拍最多接受一个样本，4096样本预约至少留出4096拍。目标样本之后所有运行槽必须共同接受同一公共样本，验证probe对每个事件断言，无样本跳过。空拍不改变相位；首个样本用当前相位相关，之后推进。

## 导航数据层级

`navigation_d1` 新增三个输出，原导航字记录逻辑保持：NH20去除后，在合法D1首字（含帧头、子帧编号和BCH检查）到达时确认数据极性。此后每完成20个1ms Prompt积分输出一个50bit/s数据位，以`nh.data_bit XOR decoder.polarity_inverted`恢复原极性。

输出是**去NH、极性恢复后的原始D1串行比特**，保留BCH校验位和原始MSB-first传输顺序；不是26位信息字段、广播星历参数或定位结果。用于确认同步的首个30位头字已在内部消耗，不补发；从下一位开始输出。下一子帧的头字在已同步时仍自然输出。导航字/时间/观测有效性仍沿用两完整连续子帧确认，不能由bit_sync_ok推断time_valid。

新流与`nav_valid`脉冲同周期稳定；跟踪失锁、重配置和复位会撤销有效性，部分NH积分及未输出电文不流入下一次捕获。既有12路120字回归证明原256位导航记录输出未破坏；六路Prompt测试单独覆盖NH相位、正反极性、错时启动、间歇Prompt与失锁重启后的逐位内容。
