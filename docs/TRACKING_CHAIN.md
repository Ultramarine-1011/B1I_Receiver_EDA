
## 2. 参考模型的因果边界

`model/tracking_reference.py` 分离三个角色：

- `SignalSource`：PRN 与量化实 IF 激励；真实码/载波相位、运动项、噪声和测试符号只在此生成。
- `TrackingLoops`：只接收 E/P/L 和从样本测得的能量，不读取 scenario、真实频偏、真实码速、NH 起点或载波相位。
- `run` 和评分：构造有明确误差的初始条件，驱动逐样本信号模型，记录相位、频率与状态误差。初始估计由测试真值加偏差构造，用于模拟捕获结果，不作为运行时辅助。

输入样本为 -3/-1/+1/+3。合成 ADC 门限取 -1/0/+1，噪声 sigma=1，实正弦幅度 `A=sqrt(4*10^(C/N0/10)/Fs)`；这些是工程激励定义，未冒充正式课程 ADC metadata。无噪声激励幅度为 2。当前符号是按真实码周期翻转的可复现测试序列，**不是完整 ICD NH/D1 数据发生器或同步实现**。

载波总频偏与物理运动频偏分开：仅运动项按 `Rc/fB1I` 进入码速。振荡器-only 场景验证不能把全部载波偏差错误地作为码辅助。

## 3. 时间与反馈研究假设

每窗口固定 N=16368 个接纳样本、Tu=1 ms；本样本用当前 Code/Carrier 相位，之后推进。窗口首末样本不重不漏。

研究模型从本地 Code NCO 的下一次码回绕开始积分（初相已经为 0 时可直接开始），此前 NCO 按样本推进但不发布相关窗口。这样以**本地码状态**靠近可能的符号边界，不读取真实 NH 边界。该启动策略尚待封装到 RTL，并须验证任意初相、较大码速差和长时间固定窗口的漂移影响。

模型暂以 128 accepted samples 作为结果到反馈生效的等待：每个新窗口前 128 样本仍用旧控制字，随后用上一窗口算出的新字。空拍不增加样本时间。该值是待与算术流水线核对的工程预算，不是正式系统 clk 或已经实现的控制器时序。必须保证实际运算最迟在该生效点前完成，或依据模型重新选择延迟并验证。

## 4. 鉴别器与连续/离散定义

DLL 候选为非相干归一化功率差：

```text
PE = IE^2 + QE^2, PL = IL^2 + QL^2
D = (PE-PL)/(PE+PL)
e_code = D*(1-delta)/2       [chip], delta=0.25 chip
```

此处误差正值表示本地码落后、应增加本地码速；理想 BPSK 在零点的增益绝对值为 `2/(1-delta)=8/3`。真实离散 PRN/噪声会改变增益，不能把这项线性校正当成全误差范围的精确反函数。分母和输入能量不足时不更新滤波器。

Costas 候选：`e_phase = wrap_pi(atan2(QP,IP))/(2*pi)`，单位 turn，区间 `[-0.25,+0.25)`。同时翻转 I/Q 不改变误差，保留 BPSK 的半周模糊。

FLL 候选：相邻有效 Prompt 的 `P[k]*conj(P[k-1])` 相位先按 pi 折叠，再除 `2*pi*Tu` 得 Hz。Tu=1 ms 时无模糊区间仅 ±250 Hz，不能宣称可直接拉入 ±10 kHz。±10 kHz 是总频偏字范围；残余频偏是不同指标。无效窗口会清除相邻 Prompt 历史，禁止把隔窗相位差按一个 Tu 计算。

PLL/DLL 使用包含 NCO 的二阶 II 型结构，积分状态与当前比例项分开：

```text
zeta = sqrt(1/2)
wn = 8*zeta*Bn / (4*zeta^2+1)
Kp = 2*zeta*wn                 [1/s]
Ki = wn^2                     [1/s^2]
I[k] = I[k-1] + Ki*Tu*e[k]
u[k] = I[k] + Kp*e[k]
```

PLL 的 e 为 turn，u 为 Hz；DLL 的 e 为 chip，u 为 chip/s 并另加标称 Rc。积分、限幅和模式切换均有显式状态。当前参考在 FLL 后切 PLL，切换时装载 `I = old_command-Kp*e` 以保持该次控制命令连续，NCO 相位不重置。FLL 增益正在研究，尚未冻结为 RTL 系数。

`linearized_poles` 将窗口平均、NCO、旧/待生效控制量和反馈延迟纳入离散状态矩阵，而非只引用连续极点。128 样本延迟、理想鉴别增益下，Bn=1/2/5/10/15 Hz 的最大极点模分别约 0.998665/0.997326/0.993288/0.986481/0.979575。该局部线性稳定性不证明非线性大误差一定拉入。

## 5. 已完成研究与失败记录

- `reports/tracking_reference/summary.json`：初版四场景研究。正负 100 Hz 残差与 ±0.3 chip 初差收敛，但 C/N0=45 的尾段锁定占比仅 0.936，未达到预先规定的 0.95。定位为单个低能量窗口立即清锁并重新等待 32 个窗口。保留原失败报告。
- 修订为连续 32 好窗口进入、连续 4 坏窗口退出的迟滞，评分门限不变。`scan_v2/summary.json` 完成 27 个参数/场景组合：DLL 1/2/5/10 Hz；PLL 5/10/15 Hz；直接 PLL 和 FLL→PLL。
- 直接 PLL 在 100 Hz 初始残差下未拉入；FLL→PLL 能拉入，说明不能只用 PLL 线性极点支持大误差捕获结论。
- DLL 1/2 Hz 在 7 chip/s 码速初差下失锁，5/10 Hz 收敛；C/N0=45 时 DLL 5 Hz 的码 RMS 约 0.00782 chip，10 Hz 约 0.01142 chip。5 Hz 是后续候选，不在组合压力与定点验证前最终验收。
- 无噪声有界动态记录 `bounded_dynamic_15Hz.csv`：PLL 15 Hz 在该 4 s 模型中动态段最大相位误差 0.032689 turn，最大频率误差 0.092868 Hz，动态段锁定比例 1。必须评价整个动态段，不能只使用动态结束后很小的尾段 RMS。
- `stress_v3/` 扩展至 ±200 Hz 残差、±0.375 chip、±7 chip/s 的组合噪声角点，以及振荡器-only 和有界动态。运行完整性以其 `summary.json` 为准。

研究筛选门限预先为尾段码 RMS≤0.1 chip、载波 RMS≤0.05 turn、频率 RMS≤5 Hz、锁定占比≥0.95；它们只是候选筛选，不是最终课程验收，也不替代瞬态最大值、收敛时间、失锁/周跳及低质量恢复检查。

有界动态采用连续相位/频率/加速度的八段 jerk 周期，jerk 序列为 `+J,0,-J,0,-J,0,+J,0`（可反号）。当前 A=26.036 Hz/s、J=26.036 Hz/s²、段长 1 s，频率附加幅值不超过 52.072 Hz；对应 V1.7 的约 5 m/s² 与 5 m/s³ 包络。初版无限延伸 jerk 会超出加速度包络，已替换；更长动态、多随机种子和完整课程 D01–D04 对应仍待完成。
