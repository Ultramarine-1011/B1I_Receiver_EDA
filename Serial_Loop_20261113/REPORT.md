## 采用的结构

- DLL/PLL 归一化采用 16 拍 radix-2 精确除法，保留整数位和 16 位小数。分母为零、比例为一及全位宽边界均有独立整数参考检查。
- FLL CORDIC 每拍执行一次旋转，共 16 拍，保持原 16 次旋转的常数、舍入、BPSK 象限折叠及 signed59 中间状态。
- 码环和载波环的 `/127875` 控制字换算共用一份精确倒数乘法，分拍保存结果。该乘法在本轮单通道中占约 4.3% 面积。
- 载波辅助 `/763` 采用 17 拍 radix-4 signed33 精确除法，初始化和反馈复用同一单元。初始化转换完成前保持采样反压，PRN 预置同时进行。
- 反馈运算期间冻结该通道的样本接纳，计算完成后再推进 NCO。反馈最长等待 40 拍，保留原来相同接纳样本序列上的逐样本数值和锁定策略。
- 公共 IF FIFO 为 64×2 bit，使用 147 个状态位及数据位寄存器。六路独立跟踪、NH、D1 和配置状态继续处理同一公共流，反压期间的输入按原始顺序排队。顶层配置与六路 `capture_ok/bit_sync_ok/nav_data/nav_valid` 端口保持兼容。[跟踪 RTL](rtl/tracking_channel_minimal.sv) [公共 FIFO](rtl/bds_bb_6ch_core.sv) [接收机引擎](rtl/bds_bb_6ch_engine.sv)

## 教师参考工程的取舍

`six_tile/README.md`、`rtl/`、`sim/tb_bdi_parallel_receiver_6sat.sv`、原仿真日志及参数说明 `.tex` 已逐项核对。

| 项目 | 教师参考工程 | 本轮选择与依据 |
|---|---|---|
| IF 和通道配置 | 4 bit 有符号六星叠加 IF，固定 SV6–11，16.368 MHz 时钟 | 课程 2 bit IF、运行时 PRN 配置、共享采样握手和独立通道状态 |
| 捕获 | 逐码片相位做 1 ms 相关，默认在六组已知相位附近各搜 5 点，捕获载波为标称 IF | 保留当前完整频率/相位粗搜和精细搜索，另做原教师捕获模块独立 DC 探针 |
| 频率搜索 | 跟踪启动后比较 −500、−250、0、+250、+500 Hz，信号源六路均为 +250 Hz | 保留原配置的 ±10 kHz 粗搜网格及 50 Hz 局部细化能力 |
| 跟踪 | 8 相位载波表、48 bit 相关器、4 ms Costas PI、移位环路增益，带教学偏置参数 | 通过精确迭代降低现有环路成本，使用原 E/P/L、锁定和载波辅助算法 |
| NH 同步 | 400 组 53 bit 累加、64 bit 分数、5 bit 位计数，另有 done 和采样相位状态 | 沿用已有 20 组 34 bit 累加和 36 bit 分数，以及五层 top-two 树 |
| 导航 | 11 bit 帧头与 50 bit 交替载荷，原 500 ms 仿真结束时各路 header/payload 均为 0 | 沿用课程 D1 极性消歧、字处理和原始导航位输出，使用独立电文评分 |
| 可综合性 | PRN 包的静态码表可综合，捕获探针已真实映射。信号源在初始化中用 `$cos` 生成载波表 | EDA 输入清单选用接收机 RTL，信号源用于仿真参考 |

教师捕获模块在默认完整 2046 码片相位范围下，实际面积为 10700.424068 µm²，setup WNS +0.839757 ns，hold WNS −0.049330 ns。其接口、频率网格、检测门限、积分统计及细化能力有差异，因此该数字用于结构成本判断。原教师测试台将未消除 Costas 极性的 raw navigation errors 作为诊断信息，原日志部分通道全部原始位反相，帧/载荷计数为零；本轮六通道评分要求消歧后的实际 D1 位与独立电文一致。[探针结果](Results/teacher_capture/area.rpt) [探针约束](Results/teacher_capture/mapped.sdc)

当前 PCPS/FFT 共用捕获引擎的可变数组仍为 1768768 bit。上一轮完整展开在 36.19 s 达到 8 GiB RSS 限制。单相关器逐点流式搜索若覆盖 4092 个半码片粗相位、41 个频点和四个 1 ms 非相干窗口，单 PRN 需要约 671.088 s 的信号时间，六路顺序搜索约 67.1 min。该估算直接来自候选数与积分时间，说明进一步串行化需要同时设计并验证搜索延迟、分级策略和检测统计。保留现有捕获链路使本轮可用同一功能边界验证跟踪优化。[完整捕获历史证据](../Backend_20261111/REPORT.md)

## 复现与证据

生产 RTL 清单为 `rtl/receiver.f`。`tracking_channel_minimal.sv` 已包含其迭代算术模块定义，测试参考、映射包装和源生成素材由各脚本显式选择。

在本实验目录中使用现有 bundled Python 依次运行 `scripts/make_core_tests.py`、`scripts/make_regression.py`、`scripts/prepare.py`，得到本目录 `inputs.tar.gz`。将该归档传入本机 VMware 客体后，可在全新运行目录执行下列入口。

```bash
ARCHIVE=/tmp/six_tile_asic_inputs.tar.gz
tar -xOf "$ARCHIVE" scripts/run_all.sh > /tmp/run_iterative_asic.sh
ITERATIVE_ROOT=/home/ICer/six_tile_asic_reproduce bash /tmp/run_iterative_asic.sh "$ARCHIVE"
```

该入口使用本机 TSMC90 库和工具路径。核心拼接引用上一轮 `/home/ICer/ic_eda_resume_tree_20261112/final_core/reports/mapped.ddc`，并逐项核对六份跟踪接口和未映射状态。目标库、工具、DesignWare、检查点和最终导出文件的实际 SHA256 已保存。各个工具阶段已经实跑，统一串联入口按相同阶段组合并完成 Bash 语法检查。[执行脚本](scripts/run_all.sh) [映射脚本](scripts/integrate.tcl) [接口保护](scripts/channel_cache.tcl)
